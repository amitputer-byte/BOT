# גן הכפל — תיקיית פרויקט לקלוד קוד

## מה יש כאן
- **`CLAUDE.md`** — כללי הברזל של הפרויקט. קלוד קוד טוען אותו אוטומטית בכל סשן. לא צריך להזכיר אותו.
- **`gan-hakefel-profiles-spec.md`** — הספק למשימה הנוכחית: מעבר לפרופילים (multi-user), refactor-first. עליו מצביעים ידנית כשמתחילים לעבוד.
- **`README.md`** — הקובץ הזה.

## ⚠️ מה חסר — להוסיף לפני שמתחילים
הקובץ **`gan-hakefel.html`** הקיים (האפליקציה עצמה) **לא נמצא בתיקייה**. הוסף אותו לכאן, באותה רמה כמו שאר הקבצים. בלעדיו אין על מה לעבוד.

> אם הקובץ נקרא אחרת אצלך (למשל `index.html`) — זה בסדר, רק ציין לקלוד קוד את השם הנכון.

## איך מתחילים בקלוד קוד
1. ודא שהתיקייה מכילה את שלושת קובצי ה-`.md` **וגם** את `gan-hakefel.html`.
2. פתח את התיקייה בקלוד קוד.
3. תן הוראת פתיחה כמו: _"עבוד לפי `gan-hakefel-profiles-spec.md`. התחל בקריאת הקובץ הקיים והצג לי מפת מבנה השמירה לפני שאתה נוגע במשהו."_
4. קלוד קוד אמור לפתוח בקריאת `CLAUDE.md` (אוטומטית) ובקריאת ה-HTML הקיים — ולא לרפקטר כלום לפני שהציג לך את מפת השמירה.

## הסדר הנכון
בסיס יציב קודם (שלב 0 + שלב 1 בספק), טסטים ירוקים, ורק אז ה-Backlog (משחקים, רמות קושי, קוריקולום). אל תערבב.
